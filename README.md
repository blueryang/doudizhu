# 斗地主 · 三人牌桌（单机版）

纯 HTML / CSS / JavaScript 的斗地主小游戏，单文件、无后端、无外部依赖，浏览器打开就能玩。

## 玩法

- 1 名玩家 vs 2 个 AI，54 张牌，每人 17 张，3 张底牌。
- 叫地主 / 抢地主（倍数递增），地主拿底牌先出。
- 完整牌型：单张、对子、三张、三带一、三带二、顺子、连对、飞机（带单/带对）、四带二、炸弹、王炸。
- 出牌验证：不符合牌型或大不过上家会提示原因；点「提示」自动找能大过上家的最小牌，再点换一种。
- 计分：底分 100，抢地主、炸弹/王炸、春天翻倍，跨局累计总分（存在浏览器本地）。
- AI：会跟牌、会忍炸弹、农民不压队友的牌。
- 音效：WebAudio 实时合成，无音频文件——出牌脆响、选牌轻点、炸弹闷响、王炸上扬、胜负小调；右上角可单独开关音效与语音，设置记在浏览器本地。
- 背景音乐：仓库根目录的 BGM.mp3 循环播放（蜜雪冰城主题曲），右上角可单独开关；换音乐只需替换 BGM.mp3 或改 audio 元素的 src。合成旋律引擎已停用、代码保留作备用。
- 手机优化：手牌放大（56×80），重叠间隔按屏幕宽度与剩余牌数自动计算、永不溢出；非己方回合的手牌压暗改用滤镜（不再半透明），消除重影。
- 语音播报：系统中文语音报出牌内容——单张/对子/三张直接报牌面（如“对三”“三个勾”），顺子、连对、飞机、三带一、三带一对、四带二、炸弹、王炸报牌型；不出报“不要”，叫/抢地主与胜负也报。

## 本地运行

直接用浏览器打开 `index.html` 即可，无需安装任何环境。
